| Field | Value |
|---|---|
| **Project** | OSQP — https://osqp.org/ |
| **Version** | 1.0.0 (`#define OSQP_VERSION "1.0.0"`) |
| **License** | Apache License 2.0 |
| **Copyright** | Copyright 2021 Bartolomeo Stellato, Goran Banjac, Paul Goulart, Stephen Boyd |
| **Upstream** | https://github.com/osqp/osqp · codegen template from https://github.com/osqp/osqp-python |
| **Location** | `src/shinro/runtime/codegen/emosqp/` |
| **How it got here** | Generated by OSQP's embedded code-generation tooling (headers carry an autogenerated timestamp). Committed rather than built at install time. |

**What is included.** The embedded solver source: the ADMM solver core
(`src/`), QDLDL sparse LDL factorization (`src/qdldl.c`, `inc/private/qdldl.*`),
the generated workspace and problem-specific bindings (`workspace.c`,
`emosqp.c`, `bindings.cpp`), and the public headers under `inc/public/`.

**License text.** The full Apache License 2.0 text is reproduced in
[`licenses/Apache-2.0.txt`](licenses/Apache-2.0.txt), as required by section 4(b).

**Notice retention.** Three files retain their upstream Apache notices
(`src/qdldl.c`, `inc/private/qdldl.h`, `inc/private/qdldl_version.h`). The
remaining generated files did not carry notice headers in the upstream codegen
output; this document supplies the attribution for those.

**Modifications.** `bindings.cpp` is local glue (pybind11) written for this
project, not upstream code. `solver_meta.zig` is local. The generated C sources
are unmodified codegen output.

## Adding an entry

1. Add the project, version, license, copyright line, and the in-repo location.
2. If the license requires the full text to travel with the code, put it under
   `licenses/` and link it.
3. If the license is not permissive (GPL, AGPL, SSPL, or a proprietary vendor
   license), **stop and check before vendoring** — it may not be compatible with
   this project's outbound license.

**Rationale.** Licenses that require attribution (Apache 2.0, BSD, MIT) oblige
us to reproduce copyright notices and, for Apache 2.0, ship the license text.
This file is the single place that obligation is discharged.
