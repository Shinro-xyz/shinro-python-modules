### 2026-09-09 22:45 UTC — unify sim/compile model derivation

Closed the A/B derivation gap between the sim and compile paths (the "leaky
abstraction" from the external-user DX review): a scenario with a plant-only
`[plant]` section now derives `n_x`/`n_u` and the `A_dynamics`/`B_dynamics`
model from the plant in **both** paths, so "specs + weights" is enough and the
two paths can never disagree about the model.

- `utils/linearization.py` — new `derive_model(plant)` (linearize at default
  op point + Euler-discretize at `plant.dt`) and `inject_model(cfg, plant)`
  (fills `A_dynamics`/`B_dynamics` from the plant when a config omits them;
  explicit model wins). Single source of the derived model.
- `codegen/scenario_gen.py` — `load_scenario` now surfaces the `[plant]`
  section; `_validate_compile` makes `n_x`/`n_u` optional (derived from the
  plant when absent); `gen_scenario` derives dims + model when a plant-only
  `[plant]` (type + config) is present. Sim-backed `[plant] name = ...`
  sections are sim-only and ignored by the compile path.
- `codegen/build.py` — `build_composed_graph` accepts in-memory config dicts
  (via a `_factory` helper) so injected configs can be passed directly.
- `factories/scenario_factory.py` — `_create_loop_role` now delegates to the
  shared `inject_model` (same behavior, deduped).
- New config: `configs/scenarios/cartpole_lqr_kf_derived.toml` — CartPole +
  LQR + KF with `[plant]`, no hand-written A/B or n_x/n_u.
- Tests (`test_codegen_build.py`): `inject_model` unit test (derived shapes
  (4,4)/(4,1), explicit wins) + graph-identity test proving the derived
  scenario composes the **same** graph as the explicit-A/B path.

Suites: sibling **1019 passed** (6 skipped, 96 deselected), ruff clean;
shinro-bench closed-loop fast subset (14 non-sweep cases) green against the
modified source. The A/B trap is now closed: the shipped `lqr_cartpole.toml` /
`kalman_cartpole.toml` (which omit A/B) are correct on the compile path too.
