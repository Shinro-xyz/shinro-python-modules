### 2026-08-27 — docs-drift fix: in-repo docs, component catalog, MCP packaging

**What was built.** A docs-drift cleanup pass. The repo's documentation had
rotted against the code: the README pointed at external docs.shinro.xyz pages
and a hand-maintained file tree, AGENTS.md's component table was stale (missing
MPPI, SMC, OnnxRL, DoublePendulum, the codegen pipeline, and the runtime), and
the MCP server was still documented as a raw `python shinro_mcp_server.py`
invocation after it had been packaged as a `shinro-mcp` console script.

**Why.** Docs drift is the failure mode that costs every future session time:
the component catalog, the codegen pipeline, and the MCP entry point had all
moved on while the docs described the old layout. The fix makes the repo
self-describing — all six guides now live in-repo under `docs/` (no internet
required) and the README points at them instead of duplicating content that
drifts.

**Key changes.**

- **MCP packaging.** `.mcp.json` and `docs/mcp_server.md` now use the
  `shinro-mcp` console script (entry point `shinro.mcp.server:main` in
  `pyproject.toml`), with `python -m shinro.mcp.server` as the fallback when
  the script isn't on `PATH`. The old top-level `shinro_mcp_server.py` path is
  gone from all client configs.
- **Component catalog.** New `docs/components.md` — every registered component
  (class, registered name, file, config), cross-checked against the registry.
  AGENTS.md's component table was rewritten to match reality (shipped vs
  planned/experimental) and now links to it.
- **Codegen docs.** `docs/codegen.md` updated from "slice b is future work" to
  the shipped reality: `lower_zig.py` serializes a composed graph to
  `runtime/graph_data.zig`, the comptime-unrolled VM in `runtime/lower.zig`
  executes it, and `tests/test_zig_lowering.py` cross-checks the `.so` against
  the interpreter to float-exactness. Documented the host-only op set (`copy`,
  `tanh`, `relu`, `exp`, `argmax`, `one_hot`, `slice`) and the no-heap nuance
  (comptime-shaped buffers, not no-iteration).
- **New docs.** `docs/quickstart.md` (install → TOML controller → scenario →
  trace/lower) and `runtime/README.md` (Zig VM + linalg kernels + generated
  graph). `docs/how-it-works.md` renumbered its layers and updated the codegen
  step to the shipped `.so` path.
- **README.** Now points to all six in-repo docs and carries a real
  repo-structure map (`src/shinro/`, `runtime/`, `demos/`, `tests/`,
  `lab-notes/daily/`, `scripts/`) instead of a drifting hand-maintained tree.
- **Package docstring.** `src/shinro/__init__.py` updated to the five-ABC
  framing and the full subpackage list (adds `physics_engine`, `codegen`,
  `utils`).

**Verification.** `make lint` clean; `demo_codegen.py` passes all 4 stages
(trace → compose → interpret → lower); registry and op lists cross-checked
against `docs/components.md` and `docs/codegen.md`.
