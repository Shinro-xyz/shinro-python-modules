# Lab Notes — 2026-07-27

### 2026-07-27 22:30 UTC — initial

**Change: new-plants-and-generator**

Added InvertedPendulum and CartPole benchmark plants with standalone analytical dynamics and optional MuJoCo engine mode. Both implement `dynamics()` returning continuous-time dx/dt — the hook for future nonlinear controllers (NMPC, MPPI, sliding mode) and estimators (EKF, UKF).

**New plants:**
- `plants/inverted_pendulum.py` — 2D state [θ, θ̇], 1D torque control, semi-implicit Euler, linearized model around upright, configurable damping and state bounds
- `plants/cartpole.py` — 4D state [x, ẋ, θ, θ̇], 1D force control, coupled dynamics, linearized model, configurable track limits
- `plants/quadrotor.py` — placeholder stub for future implementation

**Generic XML config generator:**
- Refactored `scripts/generate_robot_config.py` to use a detector registry instead of hardcoded LeKiwi logic
- Added `_PLANT_DETECTOR_REGISTRY` and `@register_plant_detector` decorator to `factories/registry.py`
- Each plant registers a detector that inspects XML structure (joint types, actuator types) to auto-detect plant type
- Three-tier fallback: heuristic → XML annotation → CLI `--type` flag
- Supports combined robots (e.g., LeKiwi → ArmRobot + HolonomicMobileRobot) and batch directory mode
- Physical parameter extraction from XML (masses, joint limits, damping, actuator ranges, gravity)

**MuJoCo models:**
- `models/pendulum.xml` — hinge joint, capsule rod + sphere mass, torque actuator
- `models/cartpole.xml` — slider + hinge, box cart + capsule pole, force actuator

**Tests:**
- TestInvertedPendulum: standalone dynamics, linearized model, state bounds, from_config (16 tests)
- TestCartPole: standalone dynamics, linearized model, track limits, from_config (14 tests)
- TestConfigGenerator: pendulum/cartpole/LeKiwi detection, batch mode, unknown XML fallback, CLI override (9 tests)
- All 663 tests pass across the full suite (including CI via act on 3.12, 3.13, 3.14)
