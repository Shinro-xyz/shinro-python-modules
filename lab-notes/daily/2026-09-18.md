# Lab Notes — 2026-09-18

### 2026-09-18 16:13 UTC — CI now runs the zig, mcp, integration, and lint suites

**Why.** `.github/workflows/ci.yml` ran only `pytest tests/` plus `pyrefly`,
so three whole suites were silently absent from CI: `tests/test_zig_lowering.py`
(and the zig-gated cases in `test_compile_scenario.py` / `test_measure.py`)
skipped because `zig` was never installed; the marker-gated `integration`
(MuJoCo) and `mcp` suites were excluded by the default `addopts`; and `ruff`
never ran. A green CI therefore did not mean what it meant locally. It was also
red for an unrelated reason: `test_toy_onnx_fixture_matches_its_generator`
imported `onnx.numpy_helper` before calling `importorskip`, so a missing `onnx`
raised `ModuleNotFoundError` instead of skipping.

**What.**

1. **Red fix.** Reordered `pytest.importorskip("onnx")` above the `from onnx
   import numpy_helper` in `tests/test_compile_scenario.py`, and added
   `onnx>=1.16` to `requirements-dev.txt` (matching the `[dev]` extra) so CI
   installs it and the onnx tests actually run rather than skipping.
2. **Workflow.** Split `ci.yml` into five jobs:
   - `test` — Python 3.12/3.13/3.14 matrix, `make test-all` (includes the slow
     horizon test), `fail-fast: false` so every leg reports;
   - `lint` — `make lint` (`ruff check .` + `pyrefly`);
   - `zig` — installs Zig **0.16.0** (matches `build.zig.zon`'s
     `minimum_zig_version`), runs `make test-zig`, then the zig-gated
     `test_compile_scenario.py` / `test_measure.py`;
   - `mcp` — `make test-functional`;
   - `integration` — `pip install -e '.[mujoco]'` + `make test-integration`.
   Added `concurrency` (cancel superseded runs) and a pinned `ZIG_VERSION` env.
3. **Docs.** Rewrote the stale `docs/testing.md` CI section (it claimed "no CI
   configuration in this repository"), updated the slow-horizon and integration
   bullets, and fixed its dead `.opencode/skills/...` link to `.agents/skills/`.
   Added a CI pointer to the `shinro-testing` skill.

**Design notes.** The heavy suites run once (on 3.12) in dedicated jobs rather
than across the whole matrix — that is how a developer runs them locally and it
avoids tripling the Zig/MuJoCo cost. The matrix `test` job still skips the
zig-gated tests; that is not a hole because the `zig` job runs them, and the
comment in `ci.yml` says so. `onnx` was safe to add to the shared dev list:
onnx 1.22.0 publishes a `cp312-abi3` wheel (valid on 3.12/3.13/3.14) plus a
cp314 free-threaded build.
